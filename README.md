# GameHub

GameHub brings together web games that can be opened directly in the browser, with no installation required.

## Access

| Hosting | Address |
|---|---|
| Vercel | [gamehubjogos.vercel.app](https://gamehubjogos.vercel.app) |
| Render | [gamehubjogos.onrender.com](https://gamehubjogos.onrender.com) |

## Game credits and sources

> GameHub does not claim authorship of the games, characters, trademarks, engines, or webports. The attributions below were gathered from files preserved in the repository and public sources used during integrations. When a webport's authorship could not be verified, the entry was marked as pending rather than receiving an invented credit.

Credits for authors, studios, and webport creators must remain associated with their respective works. If you are the rights holder of a listed project and would like to correct, expand, or remove an attribution, please open a request in the GameHub repository.
