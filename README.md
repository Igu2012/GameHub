# GameHub

O GameHub reúne jogos web que podem ser abertos diretamente no navegador, sem instalação.

## Acesso

| Hospedagem | Endereço |
|---|---|
| Vercel | [gamehubjogos.vercel.app](https://gamehubjogos.vercel.app) |
| Render | [gamehubjogos.onrender.com](https://gamehubjogos.onrender.com) |

## Créditos e origens dos jogos

> O GameHub não reivindica a autoria dos jogos, personagens, marcas, motores ou webports. As atribuições abaixo foram levantadas a partir dos arquivos preservados no repositório e das fontes públicas usadas nas integrações. Quando a autoria do webport não estava identificada de forma verificável, a entrada foi marcada como pendente em vez de receber crédito inventado.

Os créditos de autores, estúdios e portadores devem permanecer vinculados às respectivas obras. Caso seja titular de um projeto listado e deseje corrigir, ampliar ou remover uma atribuição, abra uma solicitação no repositório do GameHub.

## Observação sobre disponibilidade

Os webports podem ter limitações próprias de compatibilidade. Em especial, o port de Cuphead informa problemas conhecidos em algumas fases; essa informação é preservada para transparência e não substitui os direitos ou o suporte dos criadores originais.
